# Rust Car Data Project

## Overview
A Rust-based application to read, simulate, and analyze car data (OBD-II).
The goal is to start with simulations and eventually read real data from an OBD-II port (similar to Carly) and analyze it with AI.

## Requirements
- Language: Rust
- Core Features:
    - OBD-II data simulation
    - Future: Real OBD-II data reading
    - AI Analysis of car data
- UI: Advanced (not just a simple web UI)
